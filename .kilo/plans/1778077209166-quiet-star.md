# Meta Quest 3 VR Controller Mapping Plan

## Current State
The application has keyboard shortcuts for camera functions:
- `C` key: Toggle viewfinder
- `Space` key: Capture scene (when viewfinder is active)

VR support exists for locomotion and object interaction but lacks mappings for camera functions.

## Proposed VR Controller Mapping
Consistent with common Meta Quest controller layouts:

### Right Controller
- **Y Button** (button index 2): Toggle viewfinder

### Implementation Details
1. Modify `handleXRLocomotion()` function to check button states
2. Add debounce mechanism using existing `xrInteractionCooldown` map to prevent rapid toggling
3. Use button index 2 which corresponds to the Y button on the right Oculus/Meta Quest controller
4. Maintain consistency with desktop keyboard shortcuts

## Button Mapping Reference
- Button 0: Trigger
- Button 1: Grip buttons
- Button 2: X/Y buttons (right controller - Y button)
- Button 3: A/B buttons (right controller)

## Implementation Steps
1. Update `handleXRLocomotion()` function to process button inputs
2. Add button press detection for viewfinder toggle (Y button)
3. Implement debounce timers to prevent accidental rapid presses
4. Test on Meta Quest 3 device

## Code Changes Required
File: `src/main.js`
Function: `handleXRLocomotion()`
- Add button input processing
- Add camera viewfinder toggle logic
- Add debounce handling

This mapping maintains consistency with the desktop experience while using the Y button for the viewfinder toggle function.
