# Laser Pointer Feature Implementation Plan

## Overview
This plan outlines the implementation of a laser pointer feature that will attract cats in the WebXR environment. The feature will work on both desktop and VR controllers, with the laser pointer following the cursor on desktop and controller position in VR. Cats that "see" the laser pointer will approach it.

## Requirements
1. Laser pointer that can be toggled on/off with a key mapping
2. 70% translucent light beam visualization
3. Desktop: Laser follows mouse cursor
4. VR: Laser follows controller position
5. Cats detect and approach the laser pointer when active
6. Toggle functionality for both desktop and VR controllers

## Implementation Steps

### 1. Add Laser Pointer Toggle Controls
- Add keyboard shortcut (e.g., 'L' key) to toggle laser pointer
- Add UI button for laser pointer toggle
- Implement state management for laser pointer activation

### 2. Create Laser Pointer Visualization
- Implement a 70% translucent light beam using THREE.js
- Create laser beam from wand/controller position to a target point
- Add visual effects to make the laser beam more noticeable

### 3. Desktop Laser Pointer Implementation
- Track mouse cursor position
- Cast ray from camera through cursor position
- Position laser beam endpoint at intersection with ground/environment
- Update laser beam position on mouse move

### 4. VR Controller Laser Pointer Implementation
- Use existing XR controller raycasting mechanism
- Position laser beam at controller position
- Update laser beam as controller moves

### 5. Cat Detection and Response System
- Modify VoxelOcelot class to detect laser pointer proximity
- Implement "see" detection using raycasting or distance calculation
- Add new behavior for cats when they see the laser pointer
- Cats should approach the end of the laser pointer

### 6. Integration with Existing Wand System
- Extend existing wand functionality to include laser pointer
- Ensure laser pointer works in conjunction with wand features
- Maintain consistency with existing interaction patterns

## Technical Details

### File Modifications
1. `src/main.js` - Main implementation of laser pointer system
2. `src/components/VoxelOcelot.js` - Add laser pointer detection and response
3. Possibly create new component for laser visualization

### Key Functions to Implement
1. `toggleLaserPointer()` - Toggle laser pointer on/off
2. `createLaserPointer()` - Initialize laser beam visualization
3. `updateLaserPosition()` - Update laser beam based on input device
4. `detectLaserInView()` - Check if cat can "see" the laser
5. `respondToLaser()` - Implement cat approach behavior

### VR Integration
- Use existing XR controller system
- Leverage controller raycasting for laser direction
- Ensure laser visibility in VR environment

### Desktop Integration
- Use mouse position for laser targeting
- Implement raycasting from camera through cursor
- Handle mouse move events for real-time updates

## UI/UX Considerations
- Clear visual indication when laser pointer is active
- Intuitive toggle controls for both desktop and VR
- Subtle but visible laser beam that doesn't obstruct view
- Smooth cat movement toward laser endpoint

## Testing Plan
1. Test laser pointer toggle on desktop
2. Test laser pointer visualization on desktop
3. Test cat response to laser pointer on desktop
4. Test laser pointer in VR mode
5. Test cat response to laser pointer in VR
6. Verify performance with multiple cats and laser pointer

## Potential Challenges
1. Performance optimization with multiple cats detecting laser
2. Accurate raycasting for laser endpoint calculation
3. Consistent behavior between desktop and VR modes
4. Visual balance of laser beam visibility and scene aesthetics
