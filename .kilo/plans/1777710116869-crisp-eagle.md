# Treat Throwing Mechanism Implementation Plan

## Overview
This plan implements a treat-throwing mechanism for both desktop and VR interactions with ocelots. Users will have a limited inventory of treats that they can throw, and ocelots will chase and "eat" the treats, making purring sounds when they interact with them.

## Features to Implement

### 1. Treat Throwing Mechanics
- Implement treat visualization directly in main.js
- Add treat physics for movement through the scene
- Create treat throwing functionality for desktop and VR

### 2. Treat Inventory System
- Add inventory management for treats in the main application
- Display current treat count in the UI
- Implement treat replenishment mechanism

### 3. Ocelot Treat Response
- Modify `VoxelOcelot` to detect and respond to nearby treats
- Implement chasing behavior toward treats
- Add "eating" animation when ocelot reaches a treat
- Trigger purring sound when ocelot interacts with treat

### 4. Audio Integration
- Add treat throwing sound effect
- Ensure purring sound plays when ocelot "eats" treat

## Implementation Steps

### Step 1: Add Treat System Variables
- Add treat tracking arrays to main.js
