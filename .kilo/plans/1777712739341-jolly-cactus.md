# Plan: Update Toss Power Indicator and Treat Trajectory

## Goal
Update the GUI of the "toss power" indicator and modify the treat tossing mechanics to have an arc trajectory with normal gravity instead of slow falling.

## Current Issues
1. The toss power indicator is a simple vertical bar with minimal visual feedback
2. Treats move in a straight line toward their target position instead of following a natural arc trajectory
3. Treats don't fall with normal gravity but use direct positioning to the ground

## Proposed Changes

### 1. Update Toss Power Indicator GUI
- Replace the current vertical bar with a more visually appealing design
- Add color-changing feedback based on power level (green → yellow → red)
- Add animated effects during charging
- Add numerical percentage display
- Add a "ready" state indicator when fully charged

### 2. Modify Treat Tossing Mechanics
- Implement proper physics-based trajectory with gravity
- Add arc trajectory instead of straight line movement
- Make treats fall with normal gravity instead of direct positioning
- Ensure treats land above the ground level appropriately
- Add visual rotation/spin effect during flight

## Technical Details

### Power Indicator Changes
- Current: Simple vertical bar that fills from bottom to top
- New: Modern circular or horizontal meter with color transitions and animations
- Add numerical percentage display
- Add pulsing animation when fully charged (100%)

### Treat Physics Changes
Current implementation:
- Treats move directly from start position to target position
- No gravity or arc trajectory
- Direct positioning to ground level

New implementation:
- Treats follow physics-based arc trajectory
- Gravity affects vertical velocity each frame
- Initial velocity determined by throw direction and power
- Proper collision detection with ground
- Treats land at appropriate height above ground

### Physics Formulas
- Position: pos = pos + velocity * deltaTime
- Velocity: velocity.y = velocity.y + gravity * deltaTime
- Gravity: Standard Earth gravity (-9.8 m/s²) or adjusted for game scale
